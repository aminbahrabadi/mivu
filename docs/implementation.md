# v0.1.0 execution plan

README.md is the canonical product and architecture documentation. This file records implementation checkpoints and evidence.

1. **Initialization:** install repository-local JS tools, configure Tauri/Vite/strict TypeScript, preserve LICENSE, establish CI; validate frontend and Rust builds and a Linux launch.
2. **Native foundation:** implement selected-document state, Rust picker and drag/drop, bounded UTF-8 reads, friendly errors; test native validation.
3. **Markdown:** markdown-it, controlled highlight.js grammars, DOMPurify, inert task lists, constrained relative links/images; test representative and adversarial fixtures.
4. **Reader:** restrained toolbar, system/light/dark themes, per-block direction, search, zoom and shortcuts; test UI modules.
5. **Linux:** startup arguments, second-instance forwarding, foregrounding, parent-directory watcher with debounce and clean replacement; test watcher lifecycle and CLI parsing.
6. **Hardening:** review every IPC command and generated HTML, constrain resource reads with capability directories, reject active image formats, limit resource sizes; run adversarial tests.
7. **QA:** run typecheck/lint/frontend tests/Rust fmt/Clippy/tests/build; integration checks, actual measurements, desktop validation where possible.
8. **Distribution:** inspect .deb and AppImage, add pinned CI/release workflows, complete README/contributor/security/changelog docs, commit milestones, push the feature branch and create a PR if authorized credentials work.
